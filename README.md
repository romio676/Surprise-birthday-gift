# Malemnganbi Chanu — Cinematic 3D Scroll-Controlled Birthday Website

An interactive, scroll-scrubbed 3D cinematic birthday experience built with real-time video timeline scrubbing, atmospheric particle canvas, and luxury black-and-gold typography.

## Quick Local Run
Simply double-click `index.html` to open it in your browser, or run a local server:

```bash
python3 -m http.server 8080
```
Then visit `http://localhost:8080`.

## 1-Click Free Public Deployment

### Option 1: Netlify Drop (Fastest, zero install)
1. Go to Netlify Drop: https://app.netlify.com/drop
2. Drag and drop this folder (`malemnganbi-cinematic-website`).
3. Your website is instantly live with a free public URL (e.g. `https://malemnganbi-birthday.netlify.app`)!

### Option 2: Vercel
1. Upload this folder to GitHub or run `vercel` in your terminal.
2. Your public live link is generated immediately.

### Option 3: GitHub Pages
1. Push this folder to a GitHub repository.
2. In Repository Settings -> Pages, select branch `main` and root `/`.
3. Your website will be available at `https://<your-username>.github.io/<repo-name>/`.
